# Radar de Promoções

Painel móvel para acompanhar ofertas de produtos, com filtros de preço total e parcelamento.

## Estado do projeto

Projeto em configuração inicial. Os próximos recursos serão adicionados e testados um commit por vez.

## Objetivo

- Interface adaptada para celular.
- Configuração de buscas sem precisar de computador.
- Atualização automática programada.
- Hospedagem gratuita pelo GitHub Pages.

> A disponibilidade de ofertas dependerá das fontes de dados e dos limites de acesso de cada serviço.
